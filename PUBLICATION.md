# Public distribution boundary

This is a public demonstration of **Agentic Electromagnetic Defense**, published by SAWM-io. It contains simulation and client-side orchestration code, documentation, and selected synthetic numerical evidence.

## Included

- Causal signal estimators, a bounded simulated controller and calibration checks.
- A public HTTP SDK and the client-side connection to Basira, TSST and ODVL Cloud APIs.
- An explicitly offline numerical baseline, separate from authenticated Cloud operation.
- Publication copies of numerical results and English charts from the recorded experiment.

## Excluded

- Implementation source or weights of the private SAWM, Basira, TSST and ODVL engines.
- Active keys, credentials, private environment files and original private Cloud receipt journals.
- Customer data, production databases and internal deployment configuration.
- A hardware implementation or claim of electromagnetic-pulse neutralization.

Public evidence files retain numerical measurements but replace or omit laboratory identifiers and internal filesystem paths. They are not byte-for-byte original Cloud receipts. File checksums verify the published files, not access to the original laboratory account. The original experiment and the newly packaged runnable example are clearly distinguished in the results documentation.

Cloud operation requires the user's own authorized account, credentials, grants and available quota. Publishing the client does not expose or grant access to the hosted engine implementation.
